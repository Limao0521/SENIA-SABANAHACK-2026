# Replay pack (twin/replay)

Pre-computed SONIC co-speech arm motion + audio, so the twin runs can be replayed without StreamTalk/GMR/SONIC (no GPU stages).

## Contents
- `commercial/` : the 19-line "X2 Commercial Show" (IndexTTS-2.5, corrected run 20261022).
  - `timeline_ultra.json`, `timeline_original.json`: per-robot timelines (lines, presets, look intervals) on the conversation clock; `clip` names resolve inside this folder.
  - `orden_de_pistas.csv`: line order, WAV file, robot, scene, text. `audio/<clip>.wav`: the 19 WAVs.
  - `motion/<clip>/<clip>_arms.npz`: SONIC arms for each clip.
- `visits/<rank>/<turn>/<turn>_arms.npz` + `visits/<rank>/<turn>/<turn>.wav`: 31 SONIC arm tracks of the simulated visits (ranks vip, staff, guest, regular, external) and their turn audio (16 kHz mono WAV, the `wav16/` file of `visits_v2/<rank>/sonic/<turn>/`, the one that matches the arms timing). Same layout as `visits_v2/<rank>/sonic/<turn>/`.
  `regular/_seed1_GMR_FAIL_v2visit_regular_t01_guidance/` is a failed GMR seed variant kept for reference; the 30 real turns are the 5 ranks x 6 turns (`t00`-`t05`).
- `presets_c08/`: c08 preset latency/timeline metrics read by `p4_timeline.py`, `analyze_*.py`.

## Formats
`*_arms.npz`, 50 Hz, frame 100 = audio t0 (frames 0-99 are the lead-in): `t` (N,), `cmd` (N,14) commanded arm joints (L7,R7 order `names`), `sonic_actual` (N,14),
`gmr_desired` (N,14), `waist_head` (N,5) + `waist_head_gmr` (N,5) (`waist_head_names`), `pelvis_z`, `tilt`. Consumers use `cmd[100:]`, `waist_head[100:, :4]`.

## Replaying on the twin (twin up and STABLE, see ../SETUP.md; from `HRIEGO_gesture/twin`)
```
# commercial show: rebuild timeline/ref from this pack, run both robots, metrics
export COMMERCIAL_SHOW_DIR=$PWD/replay/commercial
python3 p4_timeline.py && python3 p4_commercial.py ultra,original 1 && python3 analyze_p4.py 1
# visits: place the arms where the orchestrators expect them, then run
for d in replay/visits/*/*/; do r=$(echo $d|cut -d/ -f3); t=$(basename $d); mkdir -p ../visits_v2/$r/sonic/$t; cp $d/${t}_arms.npz ../visits_v2/$r/sonic/$t/; done
python3 run_visits.py --visits vip --rep 1        # or: python3 mission_4e.py vip ; python3 run_c12.py --turns subset --variants V0,V1,V2 --reps 2
```
(`p4_timeline.py` also re-reads `p4_manifest.py` outputs under `runs/p4_commercial/plans`, already committed.)

## Provenance / limits
Audio: IndexTTS-2.5 (CUDA, bf16, ES, fixed emotion vectors, `use_random=False`), synthetic speech, generated by the Laplace voice experiment `x2_commercial_show_indextts_corregido_20261022`.
Visit audio is Supertonic (the 16 kHz copies under `visits/` come from `visits_v2/<rank>/sonic/<turn>/wav16/`; 44.1 kHz originals stay in `visits_v2/<rank>/wav/`, not in this pack). Preset animation CSVs (BOW/HEART/APPLAUSE/FAREWELL...) are AgiBot MC assets, external, not included.
